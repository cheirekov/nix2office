# Разработка и проверки

Единната проверка локално и в GitHub Actions е:

```sh
nix flake check --no-write-lock-file --option builders ''
```

Тя изпълнява Python тестовете, четирите NixOS оценки без system build,
форматирането на README набора файлове и deadnix. Ръчните README команди
остават валидни. Не са нужни тайни, реален deployment или remote builder.

RustDesk integration тестът използва същия чист Nix evaluator и същите Python
assertions както при ръчно изпълнение. В изолираната Nix проверка оцененият JSON
се подава предварително, за да няма вложен Nix daemon или мрежово изтегляне.
Тестовият checkout е временно празно Git хранилище, без deployment данни.

Прегледът на statix repeated-key предупрежденията установи групиране на
различни вложени атрибути (boot, services, hardware, apps и др.), без намерен
неволен override. Стиловото им пренареждане е оставено извън тези промени.

За автоматично влизане в средата инсталирай direnv и неговия shell hook,
прегледай `.envrc` и изпълни `direnv allow` в проекта. След промяна на flake
провери `direnv status`; при остаряла среда използвай `direnv reload`.
Алтернативата остава `nix develop`.

## Обновяване на ръчни източници

`packages/artcraft.nix` съдържа четири фиксирани upstream източника;
`packages/libreoffice-bg.nix` фиксира езиковия пакет. Тази реализация не сменя
техните версии или хешове. При бъдещо обновяване:

1. Провери официалния release и точния URL, версия, архитектура и лиценз.
2. От devShell изпълни `nurl --help`, после `nurl 'ТОЧНИЯТ_НОВ_URL'`.
   За директен файл използвай поддържания от тази версия `fetchurl` fetcher
   (`nurl --fetcher fetchurl 'ТОЧНИЯТ_НОВ_URL'`).
3. Пренеси проверените URL/хеш в съответния fetcher. При LibreOffice провери
   и съвпадението с версията на основния пакет от текущия pin.
4. Изгради променения пакет и провери стартиране, български език и шрифтове;
   после изпълни пълната обща проверка. Fetch hash не доказва съвместимост.

Обновяванията на pins са отделна промяна. Comma запазва собствения си фиксиран
nixpkgs и готов малък индекс.
