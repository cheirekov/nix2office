# SMB споделяне и разрешени IPv4 адреси

В `machine.toml` секцията `[sharing]` управлява SMB:

```toml
[sharing]
mode = "both"
workgroup = "WORKGROUP"
folder = "Shared"
network = "192.168.1.0/24"
read_only = false
```

`mode = "client"` включва само клиент. `mode = "both"` включва и Samba
сървър с удостоверяване за споделената папка в домашната директория на
настолния потребител. `network` определя разрешените източници за входящи
SMB връзки към TCP порт 445.

Използвайте изричен IPv4 CIDR:

| Стойност на `network` | Разрешени източници |
| --- | --- |
| `192.168.1.0/24` | Мрежата `192.168.1.0` с маска `/24` |
| `203.0.113.10/32` | Само адресът `203.0.113.10` |
| `0.0.0.0/0` | Всички IPv4 адреси |

За изрично разрешаване на всички IPv4 източници задайте
`network = "0.0.0.0/0"`. Това премахва ограничението по IPv4 източник за
SMB; удостоверяването остава задължително, без гост достъп.

Самостоятелното `0.0.0.0` е невалидно: липсва CIDR префикс и не се
преобразува автоматично в `/0`. За единичен адрес също добавете `/32`.
Не се приемат IPv6, маски като `255.255.255.0`, префикси като `/00` или `/33`,
нито адрес с хостови битове като `192.168.1.10/24`; използвайте мрежовия
адрес `192.168.1.0/24`.

Стойността по подразбиране е `0.0.0.0/0` за SMB и admin SSH. Това означава всички IPv4 източници; удостоверяването остава задължително. Можете да я стесните до LAN или един IP/32.
