# Кратка проверка на физически машини — M1

Физическо приемане: **предстои**. На 2 ноември 2026 г. общият `nix flake check`
мина локално с Nix 2.31.4: 109 Python теста, четирите NixOS оценки, formatting и
deadnix. Пакетираното `#diagnose` е изградено и изпълнено на административната
машина в текстов и JSON режим; записът е с права `0600`. Недостъпните графична
сесия и kernel log са отчетени като unknown. Facter сравнението е проверено с
fixtures по схемата на 0.4.4; реалното събиране като root предстои.

Няма потвърждение за трите офис машини. Планираме
проверка в сряда, 4 ноември 2026 г., с до три различни хардуерни конфигурации.

Не е нужна преинсталация само за диагностиката. Влез в XFCE като офис
потребителя и стартирай `nix run --option builders '' .#diagnose` от проекта
или `nix2office-diagnose`, ако вече е добавен в системната генерация.
За запазване на резултата: `--output "$HOME/diagnose.json"`.

За всяка машина запиши локално (без пароли/ключове):

| Проверка | Какво потвърждаваме |
| --- | --- |
| Инвентар | CPU/GPU, RAM, kernel, PCI адреси и текущи драйвери съвпадат с машината |
| Съществени интерфейси | Всеки storage/network/GPU/audio/USB контролер има статус; предупрежденията имат следваща стъпка |
| Desktop | Вход в XFCE, меню, браузър, документ и таблица се отварят |
| Графика | Renderer е очакваният; software rendering се отчита; VA-API е възможност, не обещание за browser decode |
| Звук | Избираш HDMI/аналогов изход в Настройки → Звук, пускаш кратък клип и потвърждаваш със слушане |
| Bluetooth | Ако има адаптер, Blueman го вижда; ако няма, отчетът не обещава такъв |
| Мрежа | Налични link/address/route; кратко отваряне на страница потвърждава реалния достъп |
| SSH контекст | Без графична сесия недостъпните проверки са unknown, без отгатване на DISPLAY |
| Facter пилот | По избор като root по hardware-bg.md; сравнение, без включване на Facter модули |

Резултатите остават локално; в публичния проект записваме само обобщени
хардуерни типове и наблюдения. Не приемаме неизвестните резултати за успех.
Няма продължителни stress тестове, автоматични backups, reboot или rollback
само за изпълнение на този списък.
